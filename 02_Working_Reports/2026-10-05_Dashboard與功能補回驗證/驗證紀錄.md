# Dashboard 與既有功能補回驗證

## 已驗證

- Dashboard 現在呈現折線趨勢、狀態環圈、產品功能／名額長條及額度比例排行。切換產品會改變圖表與目前數據，切換「用量」會顯示用量趨勢。
- 原有 8 個功能代碼與 6 個資產代碼均存在，程式逐項比對歷史版本確認。
- E2B 詳情沒有品牌樣式／內容版型頁籤，官網有這兩項，原有資產清單仍能找到。
- 使用量與額度能展開 E2B → 遠星科技 → 用戶清單；用戶詳情顯示產品、公司、用戶脈絡及用量。每項公司用量等於其用戶展示用量加總。
- 新增使用客戶能保存公司、所屬產品與方案，回到清單看到結果。
- 新增管理帳號後能看到邀請中狀態；資料與模組權限保留。
- 產品編輯能保存維護公告並建立操作紀錄。
- 通知中心原有 5 項規則均顯示，修改規則後反映啟用／停用結果。
- 公司清單的延長期限可先選 E2B／官網。選擇官網後，輸入早於原到期日的日期會顯示阻擋，沒有縮短原期限。
- 產品使用權、產品列表、功能管理、用量階層、通知、待處理、內部帳號、系統設定頁面均正常渲染；瀏覽器沒有收集到 JavaScript 執行錯誤。
- 核心規則檢查通過：產品隔離、邀請占名額、額滿重新啟用、發布範圍、額度、強制關閉、未開始期限、方案降級超額阻擋、管理帳號新增。
- 生成離線包的 JavaScript 語法檢查通過。

## 限制

沒有真實後端、寄信、部署、密碼修改或帳務。歷史趨勢及用戶用量為展示資料。用戶獨立額度上限尚待確認；此次顯示公司共用額度與用戶明細。
