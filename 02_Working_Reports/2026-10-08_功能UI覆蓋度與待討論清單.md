# DS總控台：功能 UI 覆蓋度與下次討論清單

日期：2026-10-08
狀態：討論紀錄；以下問題尚未定案，不視為正式規則。

## 本次評估範圍

使用者要求先以畫面 UI 覆蓋管理系統功能，不因未接後端、AI、寄信或尚未定案的規則扣分。
功能 UI 覆蓋度估計約 85/100，是針對公司／產品／客戶服務營運總控台的主觀評估，不是測試通過率或上線完成度。尚未完成全站瀏覽器驗證。
目前已有：營運總覽、公司與產品使用權、產品用戶、產品功能與方案、官網資產及發布、額度圖表／表格／使用紀錄、AI 客戶關懷與文字規則、人員審核寄信、通知中心、營運待辦、內部帳號、操作紀錄與系統設定。

## 建議補齊的 UI 功能（未授權實作）

1. 客服收件與案件管理：收件清單、訊息串、公司／產品關聯、附件、內部備註、回覆草稿、指派、等待客戶、結案與重新開案。可與營運待辦共用案件，不另建重複工作清單。
2. 客戶歷程：公司詳情增加歷程頁籤，串接關懷信、客服案件、通知、方案／期限／額度異動。
3. 維運事件：在營運待辦加入事件來源、首次／最近發生、重複次數、影響公司、錯誤摘要、處理結果；不必另建通用規則中心。
4. 管理操作補強：既有清單的批次指派／處理、匯出與篩選；關懷／通知既有頁面的審核佇列。
5. 視商業範圍選配合約／帳務：若總控台需管理收款，才補合約、續約、帳單、付款紀錄。完整會計／金流不是目前必備模組。
