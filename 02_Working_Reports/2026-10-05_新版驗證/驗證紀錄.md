- 14 個主要導覽頁均能渲染並顯示對應內容，瀏覽器未收集到 JavaScript 錯誤或警告。
- 晨港物流顯示 2 個啟用、1 個邀請，占 3 / 3 席；重新啟用停用帳號會出現額滿阻擋。停用一個啟用帳號後變為 2 / 3，再重新啟用另一個帳號回到 3 / 3。
- 遠星科技官網產品到期；公司仍正常，官網與 E2B 有獨立列表與使用權狀態。
- 公司功能判斷明細列出七項條件，晨港物流 AI 文案額度 200 / 200 會阻擋使用。
- 功能開放範圍可切換全部客戶／指定客戶／內部；指定清單隨範圍顯示，輸入原因後可保存展示結果。
- 新增功能從產品詳情建立，新增測試功能綁定 E2B，搜尋後能找到對應列。
- 品牌新版 v1.5.1 從套件、檢查到發布確認，列出三個採用網站；確認後三個網站版本一起變為 v1.5.1。
- 檢查通過／失敗可切換，失敗明細指出 schema 欄位問題。
- 新內容版型可儲存草稿，返回清單看到新增資料。
- 發布詳情的草稿、測試中、待發布、已發布、發布失敗、已取消都可顯示。
- 通知階段切換後，已輸入內容仍保留，可保存展示結果。
- 額度下限 720 的欄位阻擋輸入 600；調整成 1500 能顯示 720 / 1000 → 720 / 1500。
- 390 × 844 手機尺寸：導覽可展開與收合，清單頁無整頁水平溢出（375px clientWidth / 375px scrollWidth）；表格在自身容器水平捲動。
- 桌機與手機品牌預覽均已視覺檢查；測試後已恢復原瀏覽器尺寸。

## 程式規則檢查

`node check.js` 驗證產品隔離、邀請席次、重新啟用上限、公司／產品總開關、發布範圍、額度、強制關閉與未開始期限。

`node --check src/app.bundle.js` 驗證生成的離線包 JavaScript 語法。
