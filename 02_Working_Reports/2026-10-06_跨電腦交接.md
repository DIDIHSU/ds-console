## 專案目的與目前狀態

本專案是公司產品與客戶管理總後台的前端 Demo，用於需求討論與操作流程展示。目前使用展示資料，沒有真實後端；不可僅因資料寫死或未串接後端判定需求缺漏。

最新程式位於 `03_Outputs/01_UI畫面設計/00_最新版/DS總控台畫面設計/`。同層的 `DS總控台畫面設計.zip` 是交付封裝，歷史版本保留在 `99_歷史版本/`。

## 已完成內容

- 以客戶公司、各產品使用權和各產品帳號名單呈現管理流程，E2B 與官網分開管理。
- 支援公司、單一產品、單一用戶的暫停情境；邀請中帳號占名額，停用帳號不占名額，重新啟用需檢查上限。
- Dashboard 與既有功能已整理；品牌樣式和內容版型在官網產品內管理。
- 使用權操作已整併至客戶公司；獨立功能管理與產品用戶導覽已移除，操作保留在相關產品及公司內。
- 新增產品方案管理，包括帳號上限、選用狀態與影響範圍；降低上限至低於現有啟用及邀請中人數時阻擋。

## 待確認事項

- 實際方案名称、價格及內容，以及正式方案版本與舊客戶價格沿用政策。
- 官網合約到期後公開網站是否繼續顯示。
- 內容版型更新、更換、版本與內容保留規則。
- 特殊權限是否可越過到期或全域關閉、維護狀態與開關關係、額度耗盡時限制的動作。
- 特定公司上限調整、方案降級超額的正式政策，以及產品到期／整體暫停是否釋放名額。

以上未確認項目不應自行當成已核定需求；下一步依使用者指定的討論或調整項目繼續。

## 啟動與驗證

安裝 Node.js 後，在最新版程式資料夾執行 `npm start`，依終端顯示的網址開啟 Demo。也可直接開啟 `index.html` 查看。

現有 package.json 沒有外部套件依賴。修改程式後執行 `npm run build`、`npm run check`，再確認畫面。既有 2026-10-06 驗證紀錄記載方案保護、產品隔離、名額規則及建置检查通過；本次同步作業沒有修改 Demo 程式，也沒有重新執行 UI 驗證。

## 在家裡電腦第一次接續

1. 安裝 Git、Node.js 和 Codex，完成 GitHub 登入。
2. 在想存放專案的父資料夾執行：

   ```powershell
   git clone https://github.com/DIDIHSU/ds-console.git
   ```

3. 用 Codex 開啟下載的 `ds-console` 資料夾。
4. 告訴 Codex：「請先讀 README.md 和 02_Working_Reports/2026-10-06_跨電腦交接.md，接續 DS總控台專案；遵守專案既有規則。」

## 每次換電腦

開始前執行 `git pull --ff-only`。完成工作後更新進度文件、檢查變更、提交並執行 `git push`。也可請 Codex 完成這些步驟。若拉取失敗或出現衝突，先保留本機修改並處理，不要強制覆蓋。

GitHub 保存已提交並推送的檔案與版本，不包含 Codex 完整聊天、登入資訊或本機執行中的服務。暫存資料夾、套件快取及本機密鑰依 .gitignore 排除；正式產出、來源文件、驗證截圖與歷史版本一併保存。
