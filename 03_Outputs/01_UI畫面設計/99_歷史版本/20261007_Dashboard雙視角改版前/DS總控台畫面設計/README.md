# DS 總控台畫面設計

2026-10-05 Dashboard 與既有功能補回版。這是需求與階段畫面展示，使用固定情境資料，沒有串接後端。

## 開啟

直接用瀏覽器開啟 `index.html`。也可使用 Node 執行 `node server.js`，依終端顯示的網址開啟。

修改 `src` 原始碼後，執行 `node build.js` 重新產生可離線開啟的 `src/app.bundle.js`。執行 `node check.js` 驗證核心規則。不需要安裝套件。

## 建議展示順序

1. 營運總覽 → 客戶公司：查看實際服務公司、分產品使用權與名額。
2. 遠星科技：切換 E2B／官網，查看單一產品到期與獨立用戶列表。
3. 晨港物流：2 個啟用 + 1 個邀請已滿 3 席；點重新啟用查看阻擋，再停用一個帳號展示釋出名額。
4. 曜石工業／北辰醫材：分別展示整間公司暫停、單一產品暫停。
5. 公司「功能權限」→ 查看判斷：逐項查看公司、產品總開關、使用期間、功能開關、開放對象、客戶權限、額度。
6. 產品與功能 → 管理產品：新增功能綁定目前產品；開放範圍包含全部客戶、指定客戶、僅內部測試。
7. 產品與功能 → 官網方案 → 品牌樣式／內容版型：分開管理基本資料、檢查、桌機與手機預覽、測試、影響網站、歷史版本。
8. 建立新版：五個階段可直接切換，可載入展示檔案、切換檢查成功／失敗；草稿與測試可儲存展示，發布確認列出影響對象。
9. 澄藍品牌更新：三個採用網站同步更新；歷史版本提供回復確認，並保留異動紀錄。
10. 版本與發布、通知中心：切換草稿、測試、發布或發送結果等階段。
11. 使用量與額度：依產品 → 客戶公司 → 客戶用戶展開使用明細；操作紀錄保留調整前後差異與原因。
12. 產品新增／編輯、客戶新增／編輯、通知規則、內部帳號新增／重設密碼、管理安全設定：原有能力已補回。

展示操作只保留在這次開啟期間，重新整理或「重置展示」會回到預設情境。檔案選擇僅讀取檔名，通知不會寄送，發布不會部署到實際網站。

## 需求邊界

以公司為計費與服務管理單位；各產品分開使用權、帳號與名額。啟用及邀請中占名額，停用不占；額滿不能重新啟用。總控台不包含 CRM。

品牌樣式與內容版型只屬於官網方案；E2B 沒有這兩項。品牌樣式控制整體視覺，內容版型控制區塊結構；正式品牌更新會影響全部採用網站。

特殊額外開啟的優先序、公開官網到期處置、內容版型遷移及下架、邀請撤回與逾期、方案降級與計費細節、內部管理權限矩陣，仍待討論。畫面提供展示提案，不代表這些規則已定案。

## 2026-10-06 導覽與產品方案
- 功能管理整併在產品與功能內；產品用戶整併在客戶公司內。
- 方案管理維護產品方案定義，可新增／編輯、設定計費方式與公司帳號上限、停止新選用。
- 客戶選用方案與期限由客戶公司「管理方案與使用權」維護。停止新選用保留既有公司；降低方案上限不可低於啟用＋邀請中帳號數。

## 產品使用權整併
產品使用權獨立入口移除；客戶公司清單集中顯示方案、期間、付款、名額，支援產品與狀態篩選及直接管理使用權。Dashboard 狀態、到期與有效使用權入口導向公司清單並保留所選產品。
