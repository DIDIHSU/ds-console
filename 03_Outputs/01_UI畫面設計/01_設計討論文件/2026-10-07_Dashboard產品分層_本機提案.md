# Dashboard 產品分層（僅本機，尚未發布）

## 最新確認

- 重點為目前營運狀況，不擴張為營收、成長或流失分析。
- 不使用混合的「已結束任務」「任務成功率」或沒有日期的區段圖。
- 全部產品只顯示共通概況，不能把 E2B、官網的專屬用量混在一起。
- 產品需要可擴充：新增產品若無監控與使用資料，顯示尚未提供，不假設正常或零使用。
- 本輪只修改本機 UI，不推送 GitHub 或發布 Pages。

## 本機版呈現

- 全部產品：每產品一列，呈現服務狀況、有效客戶公司、近期使用公司及需關注事項。
- 單一產品：服務狀況、事件與負責人、功能使用、每日用量、各單位資源消耗及最近發布。
- 七天範圍明確標示為 2026-09-29 至 2026-10-05，沿用原展示基準日；不是今天的即時數據。
- E2B 專屬篇數、張數、分析次數與 Token／影音分鐘；官網專屬發布、訪客表單與傳輸量。不同單位不合計或混合排名，不顯示估算金額。
- 功能表依使用公司數排序；每日圖表可切換功能，點公司可进入既有公司詳細頁。
- 客戶總覽的產品組合改由資料動態產生，不限 E2B／官網兩種產品。

## 驗證

建置與既有檢查通過；新增驗證全部產品不混合用量、產品資料隔離、第三產品缺資料的顯示、七日圖表與合計一致。公司頁面與操作保留。

## 待討論

各產品什麼行為算近期使用、服務監控來源及更新頻率、具體異常門檻仍需確認。此版的使用行為定義與數值均為規劃展示。
