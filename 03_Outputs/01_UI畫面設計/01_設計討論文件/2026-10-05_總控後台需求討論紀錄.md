# 總控後台需求討論紀錄

日期：2026-10-05。隨討論持續更新。

## 討論原則（使用者已確認）

目前 UI 用於展示及釐清總控後台需求，尚無後端資料。內容可以先寫死；不可僅因資料寫死或尚未串接後端，就判定為需求缺漏。評估重點為需求規則與 UI 是否足以表達操作情境。

## 第一點：兩個產品的使用權

- 已確認現況：畫面已將 E2B 與官網方案分列，並可切換各自功能。
- 程式現況：兩列目前共用客戶的期限、狀態及額度，屬展示資料實作方式。
- 修正評估：不因共用 Mock Data 判定 UI 未分開；後續需求應確認是否需表達各產品獨立期限、狀態與額度的情境。
- 尚未確認：個別產品使用權的完整操作與規則。未將先前建議當成已核定需求。

## 第二點：功能能否使用與發布對象

使用者已同意發布對象支援：

1. 僅內部測試：客戶尚不可使用。
2. 指定客戶：只有選定客戶可使用。
3. 全部客戶：所有擁有該產品有效使用權的客戶可使用。

「全部開放」不額外限制客戶名單，仍遵守產品／功能開關、客戶使用期限與額度規則，不會讓僅購買官網方案的客戶取得 E2B 功能。

UI 使用「開放範圍」選單；選擇指定客戶時才顯示客戶選擇欄位。

尚未確認：特殊權限能否越過到期或全域關閉、維護状态與開關的關係、各功能額度用完後限制哪些動作。先前助理提出的規則為建議，尚未核定。

## 第三點：操作成功提示與結果呈現（使用者已確認展示方式）

- 展示版提供各階段的畫面顯示即可，可使用預設資料與切換方式呈現。
- 不要求從操作到結果的完整資料連動，也不要求真實保存或後端串接。
- 檢視重點為各階段畫面是否能清楚表達流程、狀態及操作結果；不因按鈕僅顯示提示而直接判定功能缺漏。
- 各操作需展示哪些階段、欄位及紀錄內容，仍隨後續需求討論確認。

## 客戶、用戶與方案（使用者已確認）

- 總控後台看到的是已在使用服務的實際客戶公司與用戶，目前沒有 CRM 需求。
- 不納入潛在客戶、銷售追蹤或未購買服務的公司建檔流程；人工補建實際使用客戶的需求尚未確認。
- E2B 客戶採訂閱制；官網採簽約方式。
- 訂閱以公司為計費單位，存在不同方案；方案定義公司底下允許的帳號數量。因此先前「方案名稱未確認」不應解讀為沒有方案；實際方案名稱、內容與官網是否採同樣方案模型仍待確認。
- 公司與其底下的用戶帳號需要在 UI 中呈現關聯，並依產品分開顯示。
- 公司開通 E2B 與官網後，分別在 E2B 後台與官網後台邀請帳號；兩個產品的使用者名單可能不同，不可假設公司帳號自動具有兩個產品的使用權。

## 暫停與到期（使用者已確認）

- 必須支援暫停整間公司、暫停該公司單一產品、暫停單一用戶三種操作範圍。
- 哪個產品訂閱時間到期，當初開通／邀請在該產品底下的所有公司帳號就不能使用該產品。
- E2B 到期不會因此阻擋仍有效的官網服務，反之亦然；公司在兩個產品的帳號名單各自管理。
- 產品到期造成的不可用與單一帳號被停用應在 UI 中區分，不應直接混成同一帳號狀態。
- 官網合約到期後公開網站是否繼續顯示，尚未確認；不可從帳號無法使用推論公開網站下線。

## 品牌樣式與內容版型（使用者已確認）

- 品牌樣式與內容版型是不一樣的東西，需分別釐清管理規則。
- 更新品牌樣式會同步影響所有採用該品牌樣式的客戶網站，全部一起更新。
- 更新確認畫面應呈現所有採用該品牌樣式的受影響客戶網站；此為上述規則的 UI 呈現建議。
- 內容版型更新、更換、版本及內容保留規則尚未確認。

## 方案帳號上限（使用者已確認與待確認事項）

- 停用帳號不占方案名額，停用後可在空出的名額內新增帳號。
- 可使用的帳號已達上限時，不允許重新啟用原本被停用的帳號。
- 新增與重新啟用均需檢查名額，不可透過重新啟用繞過方案上限。
- UI 建議分別呈現各產品的已占用／上限，以及停用帳號數；額滿時說明重新啟用被阻擋的原因。
- 邀請已寄出但尚未接受的帳號占用名額（使用者已確認）。
- 尚待確認：是否允許在總控後台為特定公司調整上限；方案降級後既有帳號數超過上限時的處理方式。
- 產品訂閱到期或產品整體暫停是否釋放名額尚未確認，不可從「停用帳號不占名額」推論整批名額自動釋放。

## 整體畫面更新（使用者已授權）

- 依已確認規則重新調整整体畫面與功能，展示各階段狀態。
- 畫面需更細緻，有系統架構與操作範圍觀念、具美感，避免全部使用卡片式布局。
- 以公司、產品使用權、產品各自帳號名單為主線，品牌樣式與內容版型分開管理。
- 未確認的實際方案名称、方案額度與其他政策只能作為標示清楚的展示資料，不視為定案。


## Dashboard 與功能保留修正

- 營運總覽使用正常 Dashboard：適合用圖表呈現的資訊使用趨勢圖、環圈圖及長條圖。
- 重整介面不得刪掉既有功能；本次已比對歷史版本補回管理操作與原始功能項目。
- 品牌樣式、內容版型僅存在於官網產品管理內，E2B 不需要也不提供。
- 使用量與額度依產品 → 客戶公司 → 客戶用戶逐層展開明細。
- 公司共用額度與用戶明細分別呈現；用戶獨立額度規則尚未確認。
