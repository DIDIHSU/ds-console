# Dashboard 與既有功能對照

這次修正保留原有系統能力，依已確認的公司／產品使用權規則調整介面。前一版的全域品牌樣式與內容版型入口已撤回：這兩項只屬於官網方案，E2B 不提供。

## Dashboard

- 四項核心數據：服務公司、有效產品使用權、維護／停用功能、高用量項目。
- 產品使用權／功能用量趨勢折線圖，可切換產品及 30／90／180 天。
- 使用權狀態環圈圖：使用中、即將到期、已到期、暫停／未開通，可點選查看清單。
- 產品功能啟用及帳號名額使用長條圖。
- 公司額度使用比例排行。
- 到期監控、待處理佇列與最近發布紀錄。

歷史趨勢為明確標示的展示資料；目前數量及曲線末端依本次展示狀態計算。用量不是營收或計費資料。

## 用量階層

產品層列出全部開通公司的服務範圍。展開公司後，先顯示各功能的公司額度、已使用量與重置日，再顯示這個產品的用戶及各項用量。點選用戶可查看詳細資料。

公司共用額度不被重複視為每個用戶的獨立額度。用戶展示用量加總等於公司用量；未配置的公司顯示未配置狀態。是否另設用戶個別額度上限尚未定案。

本版本不包含後端、實際寄信、密碼重設、部署、檔案掃描或真實帳務操作。展示資料修改只保留於本次開啟期間。
