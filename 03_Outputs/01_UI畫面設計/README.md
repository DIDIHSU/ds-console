# DS總控台 UI 畫面設計輸出

這個資料夾是目前 DS總控台 UI 畫面設計的唯一輸出入口。

## 資料夾說明

- `00_最新版`
  - 放目前要查看或交付的最新版 UI。
  - `DS總控台畫面設計.zip` 是最新版壓縮檔。
  - `DS總控台畫面設計/index.html` 是可直接打開檢視的最新版畫面。

- `01_設計討論文件`
  - 放 UI 設計討論、功能定位、需求補充與流程確認文件。

- `99_歷史版本`
  - 放舊版 zip、舊版資料夾與過程版本。
  - 只作為回溯備份，不建議作為目前最新版使用。

## 目前最新版重點

- 公司產品固定為 E2B 與官網方案。
- 支援產品、功能、官網版型、客戶、產品使用權、額度、通知與操作紀錄的前端 Demo。
- 使用 Mock Data，可操作搜尋、篩選、頁籤、彈窗、抽屜、開關、新增、編輯與狀態切換。
