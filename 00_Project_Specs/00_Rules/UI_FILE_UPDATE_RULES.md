# DS總控台 UI 檔案更新與版本保存規則

## 核心原則

最新版永遠只維護同一份固定名稱，不用版本號命名。

最新版固定放在：

```text
03_Outputs/01_UI畫面設計/00_最新版/
```

最新版固定命名為：

```text
DS總控台畫面設計/
DS總控台畫面設計.zip
```

資料夾名稱與 zip 名稱必須一致，避免多種 Demo 名稱並存造成混淆。

## 更新前

更新 `00_最新版` 前，先把目前舊版移到：

```text
03_Outputs/01_UI畫面設計/99_歷史版本/YYYYMMDD_更新主題/
```

歷史版本內可保留當時的：

```text
DS總控台畫面設計/
DS總控台畫面設計.zip
```

## 更新後

`00_最新版` 內只保留目前最新可用版本：

```text
00_最新版/
  DS總控台畫面設計/
  DS總控台畫面設計.zip
```

不要在 `00_最新版` 放舊版 zip、暫存資料夾或不確定是否可用的測試版本。

## 判斷方式

如果使用者問「哪個是最新？」答案永遠是：

```text
03_Outputs/01_UI畫面設計/00_最新版/DS總控台畫面設計.zip
```

如果使用者要直接檢查畫面，打開：

```text
03_Outputs/01_UI畫面設計/00_最新版/DS總控台畫面設計/index.html
```
